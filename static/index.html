Key NLP Architecture Highlights:
  • Synonym Ontologies: Automatically projects colloquial terms (e.g. "charger", "charging adapter", "power brick") into unified semantic concept spaces.
  • Subword N-Gram TF-IDF Vectorization: Captures typo tolerance, compound words, and morphological variations.
  • Weighted Multi-Attribute Scorer: Balances text semantics (40%), canonical cluster (35%), campus zone proximity (15%), and visual attributes (10%).
  • Explainable AI (XAI): Each match provides explicit transparent justifications for why two reports belong to each other.
